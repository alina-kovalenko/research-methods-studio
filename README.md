# Research Studio — Research Methods and Tools

A combined study guide and interactive midterm-preparation website.

- Complete guide across five topics, with 39 substantive sections, diagrams, worked examples, glossary and source references.
- 150 single-answer multiple-choice questions with explanations for every option.
- 12 original fictional article cases and 72 written analytical tasks.
- Practice exams with 28 MCQs and 12 article tasks, implementing a 70%/30% practice split.
- Bookmarks, mistake review, browser-local saved progress, printable notes and self-assessment rubrics.

## Open the website

GitHub Pages publishes `index.html` from the root of the `main` branch. The complete application, styles, fonts and question bank are bundled in that one file; no build or server is required. It can also be opened locally in a modern browser.

The Study guide and Topic lessons sections contain the learning material. Question bank, Article lab and Mock exam provide practice on the same site.

## Accuracy and privacy

Course references identify the conceptual basis and physical PDF pages. Official provider documentation is linked for database clarifications. Original lecture PDFs are not redistributed.

Practice article passages and numerical results are fictional and explicitly labelled. Written answers use self-assessment rubrics, not automatic AI grading. Mock timing, question count and marking are practice settings, not an official teacher specification.

Answers and progress stay in local browser storage; application code does not transmit them. Progress is specific to the device, browser and website origin. Export it from Review & progress if needed.
